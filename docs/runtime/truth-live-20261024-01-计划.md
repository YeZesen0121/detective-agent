本机技能名对应 `subagent-driven-development` / `executing-plans`。本轮由 P 当前对话直接执行；用户已经要求继续实施，无需再次确认既定需求或执行方式。

**Goal:** 在明确上限内完成一次真实 W HTTP→宿主→I→供应商→预算/快照的 truth 联调，并交付可直接转发的 I/W/E 接续任务。

## Global Constraints

- 授权核对：需求澄清 Q14/Q27 和 PRD §预算确认初始 300 元、演示预留、不是无限授权；历史 0.10 元探针授权已用于旧探针。本轮直接指令授权执行新的有限 truth 联调，P 在初始额度内选取下述最小子限额，不购买资源包，不改变正式演示资金。
- campaign 固定 `truth-20261024-01`；最多 **0.10 元（100000 moneyMicros）**；搜索 1、读取 1、模型 1，总计最多 **3 次供应商尝试**，输入最多 24000、输出最多 1800 token，活动最多 120 秒。
- 按已复核高峰上界，三次预留最高 0.026+0.005+24000×0.000002+1800×0.000008=0.0934 元。实际账单未知；unknown 保留预留，不自动重发，不通过新建目录/换 campaign 再花一次。
- 本轮问题固定为“Node.js 是开源、跨平台的 JavaScript 运行时环境，这一说法是否有 Node.js 官方材料支持？”。这是最小事实链路样例，不代表多源冲突/复杂真假核验通过。
- 仅从真实元宝返回项中选首个 nodejs.org 的主页或 about 页面，不凭已知 URL 伪造搜索返回；若没有合格结果就结束。筛选会在报告显式记录，不代表普通产品默认只用一个来源。
- 凭据只由执行进程从本机 `.env` 消费，不展示/转发/提交值；默认命令只检查配置，显式 `--live` 才付费。测试网络只存在 tests，明确 controlled_fixture。
- 数据写主目录 `.local/truth-probes/truth-20261024-01/`，不碰正式数据库；不导出 cookie/访问码/环境变量。主目录 UI 与 .gitignore 在途文件保留。无 GitHub 推送。
- 价格复核：DeepSeek 官方 pricing、Fetch、腾讯元宝计费文档，2026-10-24。本轮沿用保守价格版本，不把免费活动/缓存折扣计入可用额度。

## Review Focus

- 再次执行命令不能刷新预算：原子 wx campaign 锁，第二次明确拒绝，网络增加 0。
- 搜索未返回准许来源：不补造 URL、不直读已知网页、不使用 fixture 回退。
- 超时/鉴权/解析失败：停止后续调用，保留 unknown 与已有材料，不输出 Key 或原始错误。
- 程序 completed 不代表语义通过：分别记录工具链、结构/闭包、来源支持、未核验项；人工复核摘录与结论，不能用预置答案验证“成功”。
- 独立 UI 不被接线变更冻结：I/W/E 任务限制各自目录，公共接口交 P；只新增任务文件，不替其他对话写 UI。
