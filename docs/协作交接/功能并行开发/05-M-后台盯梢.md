交付报告放在本角色获准的报告路径。逐项写：任务ID、基准SHA、最终SHA、分支、文件清单、实际命令/退出码/测试数量、对应AC、参考文件及采用/舍弃机制、真实/受控边界、未完成项、P需接入的导出/接口、费用（本轮应为0次真实调用）。代码与报告一起提交。

## M1：定义模块私有宿主端口

**文件：** watch/ports.ts、scheduler.ts、check.ts、index.ts；tests/watch/scheduler.test.ts。
以下为 P 本轮预留的模块接缝，不声称 G0 shared 已有这些函数。类型导入 shared；无需改公共 contracts/ports。
    type WatchLease = {
      watch: Watch; check: WatchCheck; context: InvocationContext;
      before: ResultVersion;
    };
    type WatchExecution = {
      candidate: ResultPayload | null;
      readFailures: Array<{ sourceId: string; errorCode: string }>;
    };
    type WatchFinish = {
      kind: 'changed' | 'unchanged' | 'unknown';
      candidate: ResultPayload | null; decision: WatchDecision | null;
      reason: string;
    };
    interface WatchRuntimePort {
      claimDue(now: string): Promise<WatchLease | null>;
      claimManual(sessionId: string, watchId: string, now: string): Promise<WatchLease | null>;
      heartbeat(lease: WatchLease, now: string): Promise<boolean>;
      execute(lease: WatchLease, signal: AbortSignal): Promise<WatchExecution>;
      compare(input: WatchComparisonInput, signal: AbortSignal): Promise<WatchDecision>;
      finish(lease: WatchLease, result: WatchFinish, now: string): Promise<boolean>;
      fail(lease: WatchLease, safeCode: string, now: string): Promise<void>;
    }
P用I的runInvestigation/compareWatchResult实现execute/compare，并包装预算服务。claim返回null表示未取得合法执行权，不猜是否已发送网络。finish的false表示已失去提交权/基线失效，不重试创建通知；显著变化必须有candidate和合法decision。
P实现claim/heartbeat/finish/fail的事务：状态、scope、租约epoch、前基线、同案活动锁与期限同时校验。M测试double只能证明调用顺序，不能证明SQLite跨进程原子性。
    createWatchScheduler(port: WatchRuntimePort, clock: { now(): string }): {
      tick(): Promise<void>;
      checkNow(sessionId: string, watchId: string): Promise<void>;
      stop(): Promise<void>;
    }
tick由P常驻宿主每30秒调用；M不在import时启动定时器。心跳采用可注入timer在M工厂的可选第三参数中实现，默认30秒；stop abort所有活动并等待清理，不再claim。
