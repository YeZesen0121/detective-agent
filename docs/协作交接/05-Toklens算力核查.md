## 接入路径

按 [Toklens 使用手册](https://toklens.ai/zh/manual)：活动页创建活动 Key，选择 Windows 接入指引，在本人电脑运行生成的命令，随后用 codex-toklens 启动 CLI。生成命令可能含 Key，不应传给队友或提交仓库。各人使用各自额度。首个请求后检查用量明细；标准模式起步，Fast 按标准价两倍计费。

API 服务地址为 https://lax.toklens.ai/v1，支持 Responses 和 Chat Completions。网站后端可以据此准备兼容适配，但真实工具调用、结构化输出、图片理解及活动权限仍需实测，不能仅由协议兼容推断。此额度不覆盖元宝搜索、语音服务和服务器费用。

Codex 桌面版也有官方自定义网关配置路径，见 [OpenAI 网关接入文档](https://learn.chatgpt.com/docs/enterprise/connect-to-a-gateway)。Windows 用户配置位于 %USERPROFILE%\.codex\config.toml；需正确的模型、provider、base_url、Responses 协议和凭证来源。不要直接覆盖已有配置；工具、插件权限仍单独配置。启动后检查 provider/model，再核对 Toklens 账单，不能靠询问模型自报身份验真。
