## 2分钟主线

1. **0–20秒：先给几条模糊记忆。** 原题为“动画电影、音乐、灵魂世界”；后续明确“成年男老师”，“好像弹钢琴”一直保持不确定。展示当前报告识别出的《心灵奇旅》（Soul），不说百分之百猜中。
2. **20–55秒：为什么不是直接猜？** 展示实际报告的来源与引用，指出中学音乐教师、爵士钢琴、进入灵魂世界这些原文对应。两份正文已被读取、完整范围筛查、新evaluate及独审；不是根据标题或摘要生成片名。
3. **55–85秒：追问能接着这个版本解释。** 在固定版本追问区打开已保存问题“只依据这个固定版本已经核验的材料，解释为什么这些线索指向这个候选……”。已有真实解释保留时间、适用条件、未知和不确定记忆；没有搜索新材料。文字伴读已生成，可以作为可选支线，不演示未开通的朗读。
4. **85–110秒：调查过程有历史。** 点击“返回旧版→”看之前证据不足的版本，再点“看新版→”。这个旧版已有更新时会跳当前最新反例版；如要回成功版，使用上方固定成功链接。报告正文、原引用、核查时间均没有被新版覆盖。实际Edge已验证成功版与其前一版往返（当时尚未追加反例）。
5. **110–120秒：交付可带走的结果。** “复制结论＋出处”的实际只读载荷已核对，完整保留条件、未知、核查时间和5个来源URL。操作系统剪贴板权限未测试，不能把按钮存在当已验证该权限。
