# UI 独立协作边界与交接

日期：2026-10-24。用户明确：UI还要与AI单独讨论，必须与两位队友的服务开发隔离。本文规定边界，不代替UI设计稿，不自动创建会话或执行前端代码。

## 1. 所有权

2026-10-24补充：用户已明确允许“预留接入UI，先进行功能开发”。[W非视觉任务书](功能并行开发/04-W-UI无关前端逻辑.md)因此可现在独立实施API、model、controller和tests/web-model，不写页面/样式。U只做设计，确认后由唯一W接页面实现。本文不是已完成的UI交接稿，当前尚无已确认设计稿。

- 用户在独立会话与UI AI讨论设计。当前默认阶段为设计，不因读取本文件而开始写正式前端。
- 队友A负责调查引擎，队友B负责截图/伴读/TTS服务；两者均不得修改前端、视觉规则或页面测试。
- 用户侧在设计交接后指定唯一前端实现Agent，拥有 `src/web/`、`tests/ui/`、确认后的 `DESIGN.md` 和UI设计资料。UI会话若只做设计，后续交给另一个实现Agent即可。
- 主Agent拥有共享契约/路由/根依赖/构建/平台，不抢前端页面所有权。G0可创建必要构建配置与明确标注的非产品占位页，之后前端实现交给唯一写入者；主Agent与UI Agent避免同一文件同时改动。
- UI引入包、改HTTP字段或需要新状态时提出变更单，主Agent统一更新公共接口/依赖，再通知相关人。

## 2. 可以独立讨论的内容

信息层级、页面布局、证据展开、中文排版、颜色与字体、侦探气质、响应式布局、伴读呈现和操作细节。PRD的暖白/深色文字/适量强调色为既有起点，最终视觉方向由独立UI会话收敛，不让后端Agent提前定稿。

OJO、MotionSites、DESIGN.md仅作为方法或局部参考。400积分不作可用产量承诺；不自动消耗积分、不因工具未接通阻塞后端。

## 3. UI必须保留的产品行为

- 三种基本模式与三种呈现模式分开；呈现不降低调查质量。首版开始任务时选呈现模式，不私加任务内随意切换需求。
- 结论、关键条件、未知和来源都能找到。来源状态区分全文/摘要/读取失败，引用支持关系不能被颜色或装饰掩盖。
- 调查进度来自真实事件；无依据的百分比、假搜索、预设答案不进入真实路径。
- 缺信息、等待、运行、取消、到限、部分结果、失败、无结果均有可理解的状态。
- 伴读可打断、返回和收尾，不设答题门槛；声音点击才播，可停止，换段不叠音。
- 旧报告保持原正文/引用/伴读，显著提示更新；通知打开新报告，可回旧版。
- 手机核心操作和长中文必须可用。截图、声音、来源等不能只有电脑静态设计。

## 4. 设计交接最小包

用户侧UI AI交付到规划路径 `docs/ui/`（当前目录尚未创建）：

- `design-handoff.md`：已确认/待定设计、关键页面与交互、取舍、改动影响。
- 页面状态清单：输入/澄清/调查中/简答/证据链/伴读/历史更新/盯梢/错误与空状态，按PRD覆盖，不要求每个状态一张精修图。
- 用同一案件的真实或明确合成内容作代表性稿，包含长标题、冲突、未知、多个来源，避免只用漂亮占位词。
- `DESIGN.md`：经确认后写入视觉意图、主题变量、组件和移动端规则；未确认风格不标“用户批准”。
- 消费G0提供的结果/状态/事件模型；G0尚无时先做概念稿，接口可用后对齐，不把概念字段直接冻结成后台协议。

## 5. 前端实现与验收

设计确认后，用户侧唯一前端实现Agent按[前端模块任务书](02-B-前端体验.md)与[测试方案](06-测试与验收方案.md)编码，使用统一仓库 `feat/web-workbench` 分支，按小PR交主Agent合并。主Agent确认前端分支基线和接口版本。

UI开发可先用明确标注的受控fixtures；真实交付必须接实际前后端。布局测试、视觉复核和真实调查验收分开报告。设计好看不代表调查成功，调查API成功也不代表前端完成。

## 6. 可复制给UI AI的开场提示

```text
我在开发侦探 Agent 网站。这个会话只讨论UI与交互设计，先不要编码、安装依赖或改后端。请读取 docs/协作交接/10-UI独立协作边界.md、docs/AI开发需求文档.md、docs/协作交接/02-B-前端体验.md，以及伴读参考和现有验收样例。

先用grill-me澄清真正尚未确认的视觉与交互选择，不重问已经确定的产品需求。四项调查能力、证据与不确定表达、三基本模式、三呈现模式和历史版本约束不改变。队友正在独立开发服务，你不能通过UI设计另造调查引擎或API结构。

用相同案件与内容比较设计，优先覆盖完整核心流程和失败/未知状态。最终交付按10号文件的设计交接包，让另一个前端实现Agent也能据此编码。若有接口缺口，整理给主Agent，不自行改共享契约。OJO等参考工具不自动购买或消耗额度。
```
