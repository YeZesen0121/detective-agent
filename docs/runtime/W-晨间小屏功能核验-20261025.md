## 实际失败与最小修补

1. 长 URL 撑宽来源台账：390px 台账出现约 2195px 横向内容，其他两尺寸也复现。`src/web/main.tsx` 仅为来源列表的 flex 文本子项设置 `minWidth:0` 与 `overflowWrap:anywhere`，不更改全局 CSS、主题、字体或布局。
2. 伴读收尾/重开后焦点回 body：三个尺寸均实测 inactive。`CompanionPanel.tsx` 记录显式动作的焦点意图，成功且 busy/loading 完成后交接至对应控件；若用户已主动聚焦其他元素则不抢焦点，失败时清空意图。未改变控制器、接口、预算或生成逻辑。
3. 初始入口测试误用取消后已清空的 activeRunId，属于测试问题；改为在启动前等待对应 HTTP 响应、解析 `StartedRunSchema` 取得 runId，读取结果经 `RunViewSchema` 验证。

未改 P/shared/server/I/E、根配置/依赖或独立 UI 稿，没有制造新功能。

写入文件：上述两个 W 源文件；`tests/ui/media-small-screen.spec.ts`；`tests/web-model/media-http-fixture.ts`、`followup-http-fixture.ts` 的默认关闭场景选项；本报告。四条不同旅程按任务要求在三个尺寸运行，共 12 项，未新增同构 unit 测试凑数量。
