## 怎样发送

优先在原设计会话直接发送 `Hermes-UI协作包-v2-2026-10-24.zip`，让 Hermes 检查并解压到独立目录；用下面这一段短提示即可进入包内详细指令：

> 请读取我刚发的 Hermes-UI协作包-v2-2026-10-24.zip，检查后解压到新目录。先读 README-先读.md，再按 01-发给Hermes.txt 开始：沿用之前的网页和资料，保存基准后用 grill-me 每轮问我 1–3 个问题，等我回答再推进；最终按 03-最终交付给Codex.md 交付可运行源码及完整 UI 交接包。现在先盘点和提问，不要直接改版。附件不可访问时请说明需要什么路径。

入口不接收附件或工具无法访问时，再通过 UU/文件传输把 ZIP 放在队友电脑上，并提供实际路径。无需重新开会话，也无需重发每个文件。当前未实测队友入口，不能保证它能直接接收附件。

所有正文采用 UTF-8 Markdown/TXT，便于搜索、修改、版本管理和 Agent 读取；PDF/Word 不作为这次协作真源。未来的截图、录屏或可操作网页是配套证据，不能替代可编辑源文件。
