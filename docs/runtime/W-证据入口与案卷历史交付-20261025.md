## 本批完成

- 所有结果有只读证据展开/收起入口：brief 默认折叠，evidence 默认展开；不改案件原 presentationMode，不启动调查、不自动生成伴读。原伴读段落/音色与解释入口保持。此前临时三呈现切换版本按 P 修正指令存于本树忽略区 `.local/w-superseded-mode-switch/`，不进入提交。
- 命题状态、条件、关系、来源、未知可读；有 quote 显示中性“引用原文”，旧版回退 excerpt；完整摘录、定位和哈希按需展开。长 summary 不再整段放入巨型 h2，短预览及全文入口保留完整文本。仅展示投影，payload/hash/copy 不改。
- 无 claims、有 evidence：明确“尚未形成可核验命题；已有材料不代表结论”，可展开已保存材料、来源/读取程度、定位/hash/limitations；不重复列出 raw_capture_only 整份存档。
- 仅 source、无 evidence：可查看已保存线索（未核验），准确显示“只搜索摘要，未读正文”，展开读取说明和原文 URL；摘要中的程序停止标记转人话，不提升为结论。
- 当前案当前最新的 terminal partial/provider_error 可显式“继续核验本案”，复用 case/new window，调用 add_budget+previousRunId。cap 不可用禁用；显示与点击共用同一 eligibility，排除 watch、active、恢复不完整、unknown/pending 提交、已知新版、选择/刷新未决及 case/run/version 绑定不一致。不会自动续查。
- 历史案卷使用 P 认证 GET /investigations，limit=20，支持刷新、更多、空状态、错误恢复。仅当前 session，401 清空列表，旧会话迟到响应隔离；更多读取失败保留此前 rows/cursor。明确点击按记录的 case/latestResultVersionId 读取，不 start；当前案独立栏保留。无删除功能。
