核查日期：2026-10-24（北京时间）。以下是官方文档事实与本项目预算建议。尚未使用用户账号、密钥或付费调用；开通、额度、网络可达性均未实测。300 元是用户给出的总预算，不是已授权购买某个套餐。

后续Q27更新：用户表示预算不够可追加，300元现为初始预算。下文分配比例和240/300元阈值是历史候选，不是用户已批准的固定限制；应保留可配置费用控制与正式演示预留，在需要补充时说明用途及追加金额，而不是视为无限支出授权。

## 1. 元宝搜索：建议标准版服务 API KEY 接入

**16:41实施更新：** 用户实际提供腾讯云AK/SK，因此采用官方WSA SDK的TC3签名路线。一次真实调用返回standard版、10条有效结果，详情见[真实联调记录](runtime/provider-readiness.md)。下文“优先服务API KEY”保留为研究时建议，不要求用户另建密钥；其他供应商仍未实测。

官方目前提供两条接入路径：标准腾讯云 AK/SK 签名，以及更简单的服务 API KEY。服务密钥路线用后端请求 `POST https://api.wsa.cloud.tencent.com/SearchPro`，Bearer 鉴权。标准 SDK 路线用 `wsa.tencentcloudapi.com`，不是同一个域名／认证方式。[快速入门](https://cloud.tencent.com/document/product/1806/130616)、[服务 API KEY 示例](https://cloud.tencent.com/document/product/1806/130615)

**工程建议：** 优先服务 API KEY，减少签名实现；密钥只在服务端环境变量中。先用实际账号确认可以创建服务密钥，再决定是否退回官方 SDK；不要把 SecretKey 填进 Bearer 位置。

### 当前 schema 中直接影响产品的字段

截至所读 2026-10-20 文档：`Query` 为搜索词；`Site` 可定向一个域名或排除有限域名；`Cnt` 在支持版本下可选 10/20/30/40/50；`Freshness` 提供相对或指定日期范围。返回 `Pages` 是 **JSON 字符串数组**，需要逐条解析。返回 `score` 是相关性；`date` 是来源发布时间；`passage` 为标准摘要，`content` 为动态摘要。权威度字段只在旗舰版提供，标准版不能依赖它。[SearchPro API](https://cloud.tencent.com/document/api/1806/121811)

当前 changelog 表明 2026-08-19 删除 `FromTime / ToTime`；旧教程不能继续照搬。[更新历史](https://cloud.tencent.com/document/product/1806/121822)

**需要特别保留的文档歧义：** Freshness 的日期区间描述写“日期 B 不得晚于 A”，但示例给了由早到晚的区间。不能静默替官方改语义；初版先测试 d7/d30 等相对范围，指定区间需真实调用验证。服务 API KEY 示例与最新 API 字段可能存在版本差异，adapter 要按测试响应处理，而不是假定全部字段都存在。

### 适配契约建议【不是官方 schema】

输入：query、sourceDomain、freshness、limit、purpose、claimIds。

输出归一化为：sources[]（url/title/snippet/publishedAt/publisher）、providerRequestId、providerVersion、status、diagnostic。保存合法原始响应供排查；单条坏 JSON 不得使其余合法结果全部消失。允许缺字段；不补日期、不造 URL。

错误路径至少区分：鉴权／未开通、限流、超时、返回为空、部分条目坏格式、余额／额度问题。HTTP 成功仍要检查业务 Error。暂时错误有限重试并计入预算；鉴权失败停止重试。具体错误映射依据官方响应和首次联调校准。

**两个容易误用的点：**
- 相关性 score 不是事实真实概率，不能直接渲染成“可信度 93%”。
- content 是动态摘要；若需要原文核验，要另行读取网页，并记录仅摘要还是已读正文。

### 微信公众号与抓取边界

官方 FAQ 明确暂不支持微信公众号内容。不能因为产品属于腾讯就承诺查到所有公众号；群聊截图可提取后搜索公开替代来源，找不到原文则请用户补完整截图／原链接／文本，维持未知。[官方 FAQ](https://cloud.tencent.com/document/faq/1806/121804)

此限制针对搜索产品，不能据此断言一切第三方抓取都不可能；反过来也不能承诺第三方 Fetch 必然能打开微信页。

## 2. 正文读取：搜索之外的独立能力

可选路径：

| 路径 | 优点 | 代价／边界 |
|---|---|---|
| 后端 HTTP 抓取＋正文提取 | 能自控原文、超时和缓存 | JS 页面、反爬、编码、PDF各需处理 |
| 现有模型提供商 Fetch | 少一套爬虫部署，可共用账号 | 仍受站点策略与API可用性影响 |
| 浏览器自动抓取 | 有机会处理JS页面 | 浏览器进程、资源和状态管理重，不默认引入 |
| 只用搜索摘要 | 最省实现 | 证据粒度有限，不能宣称读过原文 |

本次发现 DeepSeek 已提供独立 `POST /v1/tools/fetch`，输入 URL，输出标题与 Markdown 正文；官方明确目标站点策略会导致失败。[Fetch 使用指南](https://api-docs.deepseek.com/zh-cn/guides/search/)

**候选建议：** 元宝负责搜索，DeepSeek Fetch 仅用于读取选中的原页。不要顺手换成 DeepSeek Search 作为核心检索，否则偏离用户与赛道目标。Fetch 接入成功率尚未测，必须准备失败时“仅有摘要／原文无法读取”的路径；不用默认开一套浏览器集群。

若自行抓取用户 URL，需限制为可访问的公开 HTTP(S)，阻止本机、私有网段和云元数据地址，并校验重定向；这是 URL 抓取功能自身必须的边界。来源 HTML 作为文本，不执行其中脚本或指令。

## 3. 模型与截图

当前官方价格页把 `deepseek-flash` 对应到 **DeepSeek-V4.1-Flash-1017**，支持图片、JSON 与工具调用；不要将人类版本名直接当 API model id。[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

视觉支持 JPEG/PNG/GIF/WebP，可走 user 消息的 image_url（base64 或 URL）。即使使用 original，大图仍会进入服务端缩放流程；单图最多 1024 图像 token。因此超长聊天截图的细小文字需要裁段或请用户补清晰图，不能仅提高 detail 就保证准确。[图像理解](https://api-docs.deepseek.com/zh-cn/guides/vision/)

**建议验证后使用：** 同一个 Flash 模型处理文字与截图，避免立即增加第二家视觉服务。按 schema 提取内容再查证，不让视觉模型直接“看图判真伪”。PaddleOCR 是失败案例的后备，不默认加 GPU 服务。

产品输入上限可比供应商小得多，候选为单次最多 3 张、每张 8 MiB，长图局部补图；这是待确认的产品限制，不是官方限制。是否实现自动裁图，应由真实截图失败情况决定。

Q33后续：用户将1张/3张的选择交由工程增量判断。2026-10-24复核上述官方视觉文档，确认支持单请求多张图，数量并非接口障碍。采用最多3张的最小方案，共用附件列表与识别流程，记录图片ID和顺序，不引入编辑器；需测跨图日期/人物混淆、单张失败和请求总大小。数量选择已按授权收敛，每图8 MiB仍为工程候选，不能把文档支持当成真实账号已联调。

**编码套餐区别：** 用户的 GPT Pro coding plan 可支持开发协作，不自动提供网站后端免费推理额度。运行网站需独立服务端 API 配置。

## 4. 语音与伴读

2026-10-24 Q23后补查：[基础合成API](https://cloud.tencent.com/document/product/1073/37995)以VoiceType选择预置音色，支持Speed；从同一接口的一种预置音色扩到少量预置音色不等于建设声音生成系统，但每种仍需试听验收。其Text字段当前写明中文最大150字，长段需按实际接口限制分句/分块，缓存键须包含正文、音色、语速。不能把整段800字直接交给该基础接口。自然度、延迟、具体音色是否可用均未实测；用户尚未确认云TTS及音色范围。

浏览器 SpeechSynthesis 可以列出设备声音、播放／暂停／停止，并监听声音列表更新；需要真实设备确认中文可用性。不要声称所有浏览器声音一致或所有语音都在本地执行。[MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)

建议客户端点击才朗读，切段先停止旧队列，按短段播放，出错保留文字。用户不应因没中文音色而无法看结果。固定侦探角色形象不代表首版必须固定跨设备相同声线。

若用户更重视稳定音色，腾讯云通用 TTS 是候选：当前文档的首档后付费，大模型音色 1.2 元／万字符、超自然大模型音色 6.5 元／万字符、精品音色 0.3 元／万字符。免费包需领取且对应不同音色；我们没有确认账号资格。[TTS计费](https://cloud.tencent.com/document/product/1073/34112)

价格例：100 次、每次朗读 1500 字符，约 15 万字符。大模型音色约 18 元，超自然音色约 97.5 元（假设处于相应单价档且不计免费包）。因此不能因为“都是TTS”就混用音色预算。云TTS如果启用，应缓存同一结果段，避免重复点播反复收费。

### 可复算的单次调查估算【假设，不是实测】

假设：12 次元宝标准搜索、6 次 Fetch、累计模型输入 100k token、输出 20k token，无缓存优惠。

- 搜索：12 × 0.02 = 0.24 元。
- 读取：6 × 0.005 = 0.03 元。
- 模型：0.1 × 1 + 0.02 × 4 = 0.18 元（空闲），高峰 0.36 元。
- 合计：**0.45 元／0.63 元**，不含TTS、服务器、网络和失败重试额外开销。

200 次相同假设调查约 90／126 元。若上下文反复全文注入，token 会大幅增加；“一次模型价格便宜”不能代替总调用量核算。需要把每阶段累计输入、输出、搜索、抓取都记入账。

盯梢例：10 个开放问题，每小时每项 2 次元宝搜索，24 小时搜索成本 = 10 × 24 × 2 × 0.02 = **9.6 元／日**，还未计模型、抓取、补查。全流程频繁重跑会比这个估算更贵。

## 6. 部署与后台任务

用户允许查询超过 3–5 分钟，因此不能只比较“前端上线是否方便”。Vercel 当前 Fluid Compute 文档中，Hobby 单函数最大 300 秒，Pro/Enterprise 常规最大 800 秒，更长为特定 beta 条件；不能假定免费环境一直运行。[函数时长](https://vercel.com/docs/functions/configuring-functions/duration)

| 路线 | 优点 | 需要验证的成本 |
|---|---|---|
| 静态／Next前端＋常驻小后端 | 长任务与站内监测直接，有稳定数据库位置 | 服务器、进程恢复、HTTPS与外网连通 |
| Serverless前端／API＋任务队列／worker | 可恢复、浏览器断开不丢任务 | 服务数增加、计费和队列集成 |
| 单纯长HTTP请求＋浏览器定时器 | 初次代码少 | 断线、函数超时和离线不监测，不满足持续盯梢 |

**工程建议：** 本项目更适合“提交任务得到 runId，后台运行，前端轮询或SSE读取进度”。状态写数据库，不靠一条HTTP连接存活。常驻后端＋单实例持久化存储可作为轻量候选，暂不默认分布式队列。部署供应商尚未定，不能据此宣布50元以内必定落地。

SQLite只适合有持久卷的单实例假设；不可把函数临时盘当长期数据库。开放站点至少有每会话限额、排队与并发上限，否则公开试玩可能耗尽预算。账号体系、跨设备历史与站内通知归属需下一轮决定。

## 7. 实现前最小探针清单

这些是下一阶段真实联调任务；当前全部**待测**，没有伪造通过记录。

1. 元宝：服务密钥可用；一次常规查询；Pages逐项解析；空结果；域名过滤；Freshness相对范围。保留脱敏 RequestId、延迟和字段，不记录密钥。
2. 视觉：3种截图（群聊、海报、密集字），重点核对日期、否定词、数字、角色。结果不确定时触发补图／澄清。
3. 正文：元宝选中网页能否被Fetch读取，至少一个普通HTML、一个抓取失败样例；检验来源片段对应。
4. 模型：目标endpoint的结构化输出与工具调用，schema错误和限额路径；不是仅测“你好”。
5. TTS：演示Windows浏览器＋至少一台试用手机，中文声音、停止、连续点击、失败时文本保留。
6. 部署：外部设备打开、超过5分钟任务、刷新恢复、后台监测持续执行、服务重启后状态处理。
7. 费用：记录三基本模式各一条全流程用量；用真实分位数替换本文估算；没有免费额度也能控制总额。

完成这些探针后再锁定框架和默认参数，比先整合大型开源项目更能减少未知。
