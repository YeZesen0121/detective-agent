## 已知缺陷（如实列出）

1. 结果内容是**固定合成样例**：切换「查什么 / 怎么呈现」不会改变结果；「开查」是计时器，不是检索。
2. 「看变化」「立即查一次」「接着问」三个按钮无行为；「开伴读」可打开/关闭一个静态演示浮层，不读真实结果。
3. 案卷柜四条记录写死，点击不切换案件；`+ 新开一桩` 无行为。
4. 暗房状态不持久化，刷新回到亮色。
5. 暂停/删除只在当前页面有效，刷新复位。
6. 页面上没有「设计原型 / 合成示例」标记——用户明确决定不加（D006），与协作包要求相反。
7. 澄清等待与取消已在 v0.5 补上（D015）；仍未覆盖：长中文、多来源、伴读进行中、历史列表、真实错误码。
8. ~~「已读全文」用了「部分」的类名~~ **已修（D018）**：改为 `.rd.full`，实测该徽标 `color` = `rgb(43,107,79)`（`--ok`），同一页另外两条分别是 `.rd.full` 与 `.rd.fail`。`08-state-partial.jpg` 已按新源码重截。
