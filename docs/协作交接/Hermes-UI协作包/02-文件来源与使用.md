## 怎样发送

推荐把 ZIP 通过双方已有的文件传输方式交给队友，再解压到原设计项目旁边的独立目录。用 UU 打开原 Hermes 会话，粘贴启动提示词，并给它解压后 `00-协作说明.md` 的实际路径。若当前界面支持附件，也可附主说明；不要假定它会自动解压附件或读取同目录文件。
