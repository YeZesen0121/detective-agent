# 侦探 Agent · UI 交接包

版本 **v0.5** · 2026-10-24 · 单文件原型 · 交付范围为用户已确认的视觉与交互（见 `decisions.md` D001–D010）。

## 怎么打开

双击 `source/workbench.html`。无构建、无依赖、无网络请求，字体走系统栈。

需要 http 环境时：

```
cd source && python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/workbench.html
```

评审特定状态时加参数，界面上没有开发开关：

```
workbench.html?state=empty     空结果
workbench.html?state=partial   部分结果（有材料打不开）
workbench.html?state=limit     到限停止
workbench.html?state=failed    检索失败
workbench.html?state=clarify   澄清等待
workbench.html?state=old       旧版报告（已有更新）
workbench.html?state=v2        新版报告
```

旧版 / 新版也可以从结论页的「打开新报告」「回到旧版」链接进入。

## 这是什么、不是什么

**是**：可编辑的单文件 HTML 原型。含案卷柜、调查台（待受理 / 澄清等待 / 调查中 / 已取消 / 结论）、盯梢页、七种结果呈现（正常 / 空结果 / 部分结果 / 到限 / 失败 / 旧版 / 新版）。

**不是**：真实检索实现。所有案件、证据、台账条目、盯梢记录、时间与次数都是**合成示例**（`controlled_fixture`），没有一条来自元宝或任何接口。原型的「开查」是本地计时器播放预设事件，不产生网络请求。

## 阅读顺序

1. `DESIGN.md` —— 视觉规则与真实数值，含适用范围和例外
2. `decisions.md` —— 用户原话、决定、状态、版本对应
3. `state-matrix.md` —— 页面/状态/操作覆盖及尚缺部分
4. `handoff-check.md` —— 实际跑过的检查、结果、未执行项
5. `context-manifest.md` —— 上下文、技能、素材来源与证据分级

## 已确认真实可用的交互

| 交互 | 说明 |
|---|---|
| 五个视图切换 | 待受理 → 澄清等待 → 调查中 → 已取消 → 结论（由「开查」与「停止调查」驱动，计时器模拟） |
| 澄清：补充后开查 / 按现有线索先查 | 两条路都能进入调查 |
| 停止：正在停止 → 已取消 | 停止先显示「正在停止」，1 秒后落到「已取消」，带回已用次数与已找到材料；「继续调查」可接着走 |
| 亮/暗房切换 | 修改变量组，不持久化 |
| 调查台 / 盯梢 页签 | 互切，顶栏状态词与右栏内容同步（台账 ⇄ 盯梢记录） |
| 盯梢：暂停 / 恢复 | 卡片转灰、加「已暂停」标签、顶栏计数同步 |
| 盯梢：删除 | 行内二次确认，3 秒不点自动回退，确认后移除并更新计数 |
| 结论页：盯住这桩 | 按钮变「已盯住 · 每小时」并给出说明 |
| 历史版本：打开新报告 / 回到旧版 | 两版往返，旧版内容原样保留 |
| 复制结论 | 写入剪贴板（含结论、限定、来源、查询时间） |

## 尚未实现

- 输入模式卡与「怎么呈现」分段的选项**没有**影响结果；结果内容是固定的合成样例。
- 「看变化」「立即查一次」「接着问」只占位，无行为；「开伴读」能打开一个演示浮层并可关闭，但浮层内容是静态的，不读真实结果。
- 长中文与多来源、伴读进行中、历史列表（多案件切换）均未设计（用户已同意这类可留到开发阶段）。
- 案卷柜 4 条记录是写死的，点击不切换案件。
