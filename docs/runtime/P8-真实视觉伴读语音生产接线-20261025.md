# P8：真实视觉、伴读与语音的生产接线

2026-10-25。代码基准 `db0f243bf685fc4fc270a2ef4051be384053a9db`，P工作树 `codex/platform-lifecycle`。本轮实现正式adapter与显式组装，所有执行检查仍为controlled_fixture，**真实供应商请求0次/费用0**。

## 实现及参考取舍

### 视觉与文字

- `createExperienceModelProvider`固定DeepSeek Flash非思考JSON请求；截图只进入user的text/image_url块，私有bytes由P按owner/case/ref/hash解析后转内联data URL，bytesRef不发送给供应商。不通过公开URL暴露上传，也不另上传Files API。
- 3图、单图8MiB、8192单边/3200万像素、40MiB请求体及4MiB JSON响应上限；拒绝缺失/额外/重复/MIME错配/non-user图片。网络调用携Abort、有限timeout、禁止redirect和重试。
- 每图按1024token上界，文本UTF8字节+512边界，再预留显式max output；Flash按峰值输入2/输出8微元每token计量，不依赖缓存折扣。
- 依据：[DeepSeek视觉消息、仅user图片及用量上界](https://api-docs.deepseek.com/zh-cn/guides/vision/)、[当前型号与峰值价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。采用项目更小输入上限，不因供应商容量更大而扩大本轮额度。

### 语音

- 复用E `createSpeechSynthesizer` 与P持久授权resolver，真实 `TextToVoice` 单次TC3签名POST，不使用WSA Client冒充TTS服务，也不引入新SDK依赖。签名按官方算法，离线与锁内官方SDK signer核对（含UTC跨本地日期场景）。原生fetch便于严格控制单请求、重定向、Abort和响应上限。
- 固定基础合成API version2019-08-23、MP3、speed0；只组装已核查的两个精品音色：智柯101030、智付101055。HTTP只看到不透明voice id/label，不接受provider VoiceType或复刻音色。
- E验证SessionId/RequestId/base64/音频签名后，P在返回成功回执前再执行**2MiB平台单块上限**；失败仍可能计费，不声称为未发送。真正解码/中文试听另行验收。
- TextToVoice不返回字符usage。保持`usage:null`，`billedCharacters`明确为**请求UTF-16长度的保守计量上界**，包含空格、标点、换行和代理对；不是供应商回传用量或账单。字符预留采用同一上界，精品30微元/字符，费用和字符在原账本结算；未知失败仍保留预约。实际账单未知。
- 依据：[TextToVoice字段/响应](https://cloud.tencent.com/document/product/1073/37995)、[TC3签名过程](https://cloud.tencent.com/document/product/1278/46714)、[音色列表](https://cloud.tencent.com/document/product/1073/92668)、[字符计量与精品价格](https://cloud.tencent.com/document/product/1073/34112)。不领取免费包、不购买/开通新资源、不假设账号已经有权限。

## 正式配置

- `EXPERIENCE_RUNTIME_ENABLED=1`组装真实E文字/视觉及计价，需DeepSeek配置与同一`RUNTIME_FUNDING_JSON`；默认关闭。
- `TTS_RUNTIME_ENABLED=1`另需TC3配置、显式`TTS_VOICE_IDS=zh-male-zhike,zh-female-zhifu`。region为API可选项，未配则省略；无TTS配置时voices为空且生成503，已有文字/报告/缓存仍可读取。
- 任何truth或experience启用，main都要求`LIVE_CAMPAIGN_ENABLED=1`；同一PaidGateway与P7持久campaign，20元/100次总边界不变。只有E真实视觉组装成功时调查runtime才标supportsAttachments。
- `SEARCH_AUTH_KIND=bearer|tc3`可显式选择搜索认证。未选而两套凭据共存仍报歧义；显式Bearer搜索可与仅供TTS的TC3凭据共存。错误仅提示配置类别，不输出值。
- 正式main仍只开启已接收的truth调查profile；latest/identify/followup/watch在I策略验收之前不开放。新runtime没有安装fixture或已知答案。
