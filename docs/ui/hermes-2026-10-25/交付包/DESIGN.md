## 2. 字体

```
--serif: "Songti SC","STSong","Source Han Serif SC","Noto Serif SC",serif
--sans : -apple-system,BlinkMacSystemFont,"PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif
--mono : ui-monospace,"SF Mono",Menlo,Consolas,monospace
```

- 衬线只用于**标题与印章**：品牌字、`h1`、`h3`、印章。正文、按钮、标签全部无衬线。
- 等宽只用于**编号、时间、计数、读取程度**这类机器味的信息（`№007`、`10-24 21:40`、`已用 12/12`）。
- 字号阶梯（实际出现值）：9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 12.8 / 13 / 13.5 / 14.5 / 15 / 16 / 17 / 18 / 25（印章）/ 30+（h1）。
- 行高：正文 1.68，卡片内文字 1.6–1.7，标签 1。

**[基准]** 中文长文本未做额外断行规则；`text-overflow:ellipsis` 只用在案卷标题与盯梢卡标题。

**实现事实修正（2026-10-25 核实）**：上面两句比实现更严。实际还有两处例外——衬线也用于证据摘录 `.evq` 与命题文字 `.claimtop p`；等宽也用于证据标记 `.mark`（`↑ ↓ · !`）与读取徽标 `.rd`。准确说法是：**衬线用于「标题、印章、被引用的原文与命题」；等宽用于「编号、时间、计数、读取程度、证据标记」**。

## 3. 布局

- 三栏网格：`232px | minmax(0,1fr) | 296px`，栏间 1px 实线。
- 断点：**1240px** 折成两栏，`grid-template-columns:200px minmax(0,1fr)` + `grid-template-areas:"drawer stage" "ledger stage"`——即案卷柜在上、**台账落到左栏下方**，主区在右侧跨两行；**820px** 折成单栏（案卷柜 / 主区 / 台账依次堆叠）。
- 另有 `prefers-reduced-motion: reduce` 关闭动画。
- 主区内边距 `clamp(20px, 3.2vw, 52px)`；卡片间距 14px；区块间距 18–26px。
- 圆角：卡片 10–12px，按钮 7–9px，标签 3–5px，胶囊 999px。

**[已确认]** 三栏骨架本身保留（D002 / D004）。原先左栏底部的两行盯梢已收成一行汇总（D004）。

## 4. 组件规则

| 组件 | 规则 |
|---|---|
| 印章 `.sealbig` | 112×112，3px 实线 `--seal`，2×2 网格，25px 衬线，旋转 -8°，`mix-blend-mode: multiply`（暗房内关闭）；两字时改单列居中 |
| 结论四态计数 `.tally` | `↑ 支持 / ↓ 限定 / · 背景 / ? 未知`，数字用 mono；无数据时显示 0 而不是省略 |
| 证据行 `.ev` | 左侧标记 `↑ ↓ · !`，中间标题+摘录，右侧「读取程度」徽标；读取程度四档：已读全文 / 已读摘要 / 截图 / 未读。**徽标位在异常态会被占用**：`.rd.none`（无来源，空结果）、`.rd.fail`（失败/未读，如「重试 2 次未成功」）——这些不是第五档读取程度，是同一位置的状态覆盖 |
| 未知块 `.unknown` | 虚线边框 + 菱形图标，标题随状态变（还没确认的 / 还缺什么 / 还没查的 / 还悬着的） |
| 台账 `.log` | 竖线时间轴，条目为真实事件句式，不写百分比、不写"思考过程" |
| 盯梢卡 `.wbig` | 三列字段（频率 / 已跑 / 上次变化）+ 底部操作行；暂停态整卡降饱和 |
| 版本提示 `.vnote` | `warn` 用于「已有更新」，`info` 用于「相比上一版变了什么」；都带一条跳转链接 |
| 按钮层级 | 每屏只有一个 `.btn.dark` 主按钮；其余为描边次级 |

## 5. 状态文案规则

- 印章只说**状态**，不说**判断**：未查出 / 材料不全 / 到限未完 / 没查成 / 部分成立 / 成立。**[已确认]**（D009）
- 三种"没查到"必须彼此区分，且都不能读成"命题为假"。
- 失败写"这次没查成，不是没有问题"；到限写"不是查完了，是没次数了"。

## 6. 明确不做

- **不加**「设计原型 / 合成示例」可见标记。**[已确认]**（D006）此为与协作包要求相反的用户决定，不是遗漏。

- 不把可点击原型写成"真实调查已完成"。

## 8. 改代码前必读的实现约定

- **新增结果状态要在两处登记**：`RESULT_STATES` 加对象，`?state=` 的状态词映射表加同名字段。只加一处，顶栏状态词会显示 `undefined`。
- `NORMAL` 是脚本启动时 `snapshotNormal()` 从 DOM 读出的快照。改正常态文案要改 HTML，改快照无效（会被覆盖）。
- 状态切换只改 `.actions` 里按钮的 `textContent` 与 `display`，**不重建节点**；新增状态不要用 `innerHTML` 重写 `.actions`，否则监听器丢失。
- 复制按钮的 payload 目前是写死的（所有状态复制同一段文本），换状态不会换内容——接入真实数据时必须改成按结果生成。
