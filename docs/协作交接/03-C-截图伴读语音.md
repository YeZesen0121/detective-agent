拥有 `src/server/attachments/`、`src/server/companion/`、`src/server/providers/tts/`、`tests/experience/`。消费 G0 schemas/ports、D的仓储/所有权/预算、A提供的模型适配接口。不得独立引入第二套模型/账本或搜索引擎；前端全部由B负责。

## 工作顺序与测试

- [ ] 截图模块：附件类型/字节/解码验证、稳定id和顺序、访问归属；逐图提取文字、日期、发言人、命题和关键歧义；3图一张失败时其余不丢失。调用视觉模型经过统一预算。测试错归属、否定词、年份不明、低清图和总请求上限；AC06/07。
- [ ] 文字伴读：从不可变版本生成3–5短段，引用id必须存在，顶部结论不被隐藏；会话保存当前位置/已讲内容，打断回答后可返回；新事实问题委托普通调查追问流程，不自行偷搜。测试同一结果事实一致、旧版绑定、游标保存、未知不被删；AC05/09/10/15。
- [ ] TTS：调用前核对预置音色实际可用性，按实际接口字符限制切段，缓存键含正文/音色/语速；受会话权限保护的音频返回。取消不再排队新合成；旧请求可能完成计费。前端换段/停止由B对接。测试中文切段不删限定、重复请求缓存、错误保留文字、不同参数不串缓存；AC10/12。

统一命令 G0 后提供：`npm run typecheck`、`npm test -- tests/experience`、`npm run build`。至少一台Windows浏览器和一台手机的实际播放由B/C共同核验；服务单测不能替代设备验收。

## 减法与交付

固定侦探身份、少量短动作、预置头像/音色；不开发在线生图、声音克隆、角色编辑器、多角色群聊、教学答题或长期人格记忆。研究草稿的待定说法以PRD最新决定为准。

每个PR报告所用参考、字段/参数探针、真实/夹具、未验证项。缺账号时做契约与受控测试，不承诺云语音或视觉已跑通。第三方图片保留研究用途，不擅自作为产品商用素材。
